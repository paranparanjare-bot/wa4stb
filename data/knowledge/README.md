# Knowledge Base

Isi folder ini dengan file `.txt` milik bisnis Anda melalui Admin Panel atau secara langsung.

File ini sengaja tidak berisi identitas, nomor telepon, alamat, harga, token, atau data pribadi.
File `.txt` di folder ini dibaca otomatis oleh bot setelah disimpan.

Contoh minimal:

```text
@greeting: Halo! Ada yang bisa kami bantu?
@menu_trigger: menu, halo, hai, help, mulai
@order_trigger: pesan, order, beli
```
